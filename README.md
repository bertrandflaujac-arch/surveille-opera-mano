# Surveillance bourse Opéra de Paris – L'Histoire de Manon (15/10)

Toutes les 5 min, GitHub Actions vérifie la bourse de revente et envoie un mail
dès qu'un nouveau billet est mis en vente pour le 15/10/2026.
La surveillance s'arrête d'elle-même après la représentation.

Secrets à définir (Settings → Secrets and variables → Actions) :
`GMAIL_EXPEDITEUR`, `GMAIL_APP_PASSWORD`, `DESTINATAIRES`.
